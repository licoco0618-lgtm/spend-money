# 🌈 萌萌彩虹記帳本 (Rainbow Cute Money Tracker)

這是一個專為您量身打造的**彩虹可愛風記帳小網站**！💖  
支援**手機專屬極致版面**、**一個月觀看一次（按月檢視）**與**紀錄永久留在網站中儲存**！

---

## ✨ 最新三大強化特色

### 1. 🗓️ 一個月觀看一次（按月檢視模式）
- **獨立月份切換**：歷史明細區塊新增「**一個月觀看一次 (按月檢視)**」與「**全部歷史紀錄**」雙模式。
- **直覺翻月控制器**：點擊 `◀ 上個月` 或 `下個月 ▶` 輕鬆翻閱，並附帶 `回到本月` 快速鍵。
- **手機滑輪月份選擇**：點擊月份標籤（例如 `2026 年 10 月 ▾`），手機會直接彈出流暢的原生滾輪選單！
- **本月專屬統計**：
  - 頂部儀表板支援切換「**本月統計**」或「**歷史總計**」。
  - 明細上方常駐「**🗓️ 本月開銷小計**」，各月開銷清清楚楚！

### 2. 📱 手機使用版面完整優化 (Mobile Perfection)
- **緊湊三欄分類卡片**：在手機直立螢幕上，3 個分類（1.正餐、2.嘴饞、3.其他）精簡整齊並排，不佔滿整個螢幕，單手操作超順暢。
- **防放大跳動設計**：輸入框設定最舒適字體大小，解決 iPhone Safari 點擊輸入框時畫面被放大的問題。
- **觸控防誤觸**：所有按鈕、標籤與刪除鍵皆具備舒適的觸控熱區。

### 3. 💾 消費紀錄永久留存與安全備份
- **本機永久自動儲存**：每一筆紀錄都會即時存入瀏覽器的 LocalStorage，重整網頁、關閉瀏覽器或重開機，紀錄通通都在！
- **安心狀態標章**：頂部常駐「🟢 **已自動儲存於本機**」提示，記帳更安心。
- **一鍵備份檔案（匯出）**：點擊頂部「💾 **備份紀錄**」，即可下載 `.json` 備份檔，資料永不遺失。
- **一鍵還原記錄（匯入）**：點擊「📥 **匯入還原**」即可將備份檔匯入，跨設備更換手機超輕鬆！

## 🎨 經典萌萌彩虹功能

- 🍱 **1. 正餐** / 🧋 **2. 嘴饞** / 🎈 **3. 其他**：三種核心分類點選即切換。
- ⚡ **快捷加額按鈕**：`+35` (飲料)、`+65` (早餐)、`+100`、`+150` (便當)、`+500` 快速填寫。
- 🎊 **滿滿彩虹紙屑與愛心特效**：每次記帳成功即刻噴灑！
- 🔔 **可愛療癒音效**：內建輕快泡泡聲與過關和弦（可一鍵隨時開啟/靜音）。

---

## 🚀 如何在手機與電腦上使用？

1. **電腦直接使用**：
   - 雙擊資料夾中的 **`index.html`**，即可使用 Chrome 或 Edge 開啟。

2. **在手機上使用**：
   - 可直接使用手機瀏覽器開啟此網頁，版面已針對手機螢幕完美優化！
   - 若使用 iPhone Safari，可點擊分享按鈕選擇「**加入主畫面**」，就能像原生 App 一樣全螢幕可愛記帳囉！
